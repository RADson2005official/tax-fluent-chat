Project: Tax Filing Agent
Stack: Vue 3 + FastAPI + PostgreSQL (pgvector)

Key Paths:
- Backend: backend/app/
- Frontend: src/components-vue/ (NOT src/components)
- Models: backend/app/models.py
- API: backend/app/api/

Commands:
- Backend: cd backend && python main.py
- Frontend: npm run dev

Rules (see AGENTS.md):
- Use pgvector for vectors (NO ChromaDB)
- Frontend is Vue 3 (NOT React)
- AI agents use AutoGen (NOT LangChain)
